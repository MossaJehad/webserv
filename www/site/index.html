🌐 webserv

A compliant C++98 non-blocking HTTP/1.1 server

Welcome to Webserv

This web server was created as part of the 42 curriculum using C++98, non-blocking I/O multiplexing with a single poll() loop, standard CGI execution, chunked transfer encoding, and virtual hosts.

⚡ Core Features

  • HTTP/1.1 & HTTP/1.0 compliant
  • Single poll() event-driven reactor
  • GET, POST, DELETE methods
  • Static file serving & autoindex directory listing

🚀 Advanced Features

  • Asynchronous CGI (Python, Bash, PHP)
  • Chunked transfer request decoding
  • Custom error pages & client body limits
  • Cookies & session tracking (Bonus)
