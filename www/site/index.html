Server Architecture & Evaluation Suite

Event-driven HTTP/1.1 server built with non-blocking I/O multiplexing and a single poll() loop.

Core Reactor Engine

  • Single non-blocking poll() loop multiplexing client sockets and CGI pipes.
  • Strict RFC 7230/7231 compliance with keep-alive connection management.
  • Chunked transfer decoding for streamed request bodies.
  • Multi-port virtual host routing and per-route method restrictions.

I/O & Gateway Subsystems

  • Asynchronous CGI execution (Python 3, Bash, PHP) with timeout handling.
  • Multipart form-data parsing & raw octet-stream upload handling.
  • Custom error dispatchers (400, 403, 404, 405, 413, 500, 502, 504).
  • Stateful cookie session tracking with persistent identification.
